# Most AI capability improvements strengthen existing value themes; only revise positioning when new capabilities create customer value genuinely outside current themes

## Claim
When AI capabilities improve rapidly, most companies should update messaging, not positioning. Positioning shifts only when new capabilities create differentiated customer value that is genuinely unrelated to the company's current value theme.

## Mechanism
Dunford's positioning framework has three elements: Competitive Alternatives, Distinct Capabilities, and Differentiated Value. New AI capabilities change what a product can do, but most capability upgrades advance the same differentiated value the company already claims. When all three elements still converge on the same core value theme, the positioning holds. Only when the Differentiated Value element changes because AI enables a fundamentally different customer outcome should positioning change.

The test is concrete: does the new capability serve the same customer in the same decision context with the same alternatives? If yes, messaging updates suffice. If the new capability opens a different purchase context, different competitive set, or genuinely different customer outcome, repositioning is warranted.

Changing positioning too fast creates two failure modes. Leaning too far into future capability confuses current buyers and delays deals. Staying too anchored to current positioning makes the product look dated when competitors move.

## Conditions
Holds when: the company has an existing, validated positioning theme with proven differentiated value. New AI capabilities are improvements in speed, quality, or scope of existing functions.

Fails when: AI fundamentally changes who the customer is, which alternatives they consider, or what job they are hiring the product for. When AI creates a new category of buyer or use case, the three-element test produces a different answer.

## Evidence
Dunford uses an application security company to illustrate. When AI improves incident response sophistication, the differentiated value stays the same: better security outcomes. The competitive alternatives stay the same. The buyer stays the same. Positioning remains unchanged. Messaging updates.

> "Tilt too far into the future, and your deals will get delayed. Stick too much with what you have today, and you risk looking like a legacy offering."

## Signals
- Marketing can describe new AI capabilities using existing value language without forcing new analogies or reframing the product category.
- Sales messaging requires no new competitive-comparison cards when new capabilities ship.
- Win/loss analysis shows new buyers have the same profile as current buyers despite new AI features.

## Counter-evidence
The framework assumes the three-element structure is stable enough to use as a change test. In fast-moving categories, all three elements can shift simultaneously when AI restructures an industry. The "messaging vs. positioning" distinction also depends on how cleanly a company can articulate its current positioning. Companies without explicit positioning work will have no baseline to test against.
