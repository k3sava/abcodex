Harrison Stall. Member of Technical Staff at Anthropic, working on multi-agent systems and agentic infrastructure. Co-presented the Dynamic Workflows feature at AI Engineer New York in October 2026. His stated design principle: keep budget enforcement external to the model's context. Telling the model its token limit makes it "a little bit anxious," which changes reasoning quality, not just output length.

## Operating themes
- **Agent behavior under constraints** How in-context information, including budget limits and task scope, affects model reasoning quality throughout a session.
- **Multi-agent infrastructure design** Design principles for agent topology, session budget management, and turn-level recovery in production multi-agent systems.
