# Zach Lloyd

Zach Lloyd is the co-founder and CEO of Warp, an AI-native terminal and software delivery platform. Warp built one of the first high-volume software factories in production: their autonomous agent Wilson merges 2,000 pull requests per month sourced from Slack, routed through Linear, and validated on GitHub. Lloyd ships practical observations about what scaled AI-assisted engineering reveals, including where the new bottlenecks actually sit once code generation is automated.

## Operating themes
- **Software factories as cyclic pipelines** Full-stack automation from idea intake through merged PR, not isolated agents.
- **Measurement as the engine of improvement** Human interactions per PR as the core signal for where automation quality degrades.
- **Review as the new bottleneck** Once code generation scales, engineering throughput is limited by human review capacity.
