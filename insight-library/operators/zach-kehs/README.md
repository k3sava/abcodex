Zach Kehs. Software engineer and writer who publishes on software craft, technical debt, and the structural dynamics of codebases over time. Kehs writes from direct engineering experience and focuses on the organizational and incentive patterns that cause code quality to degrade, bringing a systems-thinking lens to what is usually treated as a technical problem.

## Operating themes
- **Technical debt as structural collapse** Why software lacks the physical feedback loops that force other engineered systems to break before they become unmaintainable.
- **Organizational incentives and code quality** How project management structures and institutional knowledge erosion drive degradation that no single engineer can prevent.
- **Software as a living system** The distinction between software and physical structures when it comes to failure modes and natural constraints on quality.
