# Laurie Voss

Laurie Voss co-founded npm, the Node.js package manager that became the world's largest software registry, and served as its COO. Currently Head of Developer Relations at Arize AI, a machine learning observability company. Voss writes publicly about the economics of software development, labor market shifts from AI, and what the collapse in code-writing costs means for the structure of engineering teams.

## Operating themes

- **Code economics and the discovery bottleneck** The cost of writing code has collapsed; Voss tracks what the labor market reveals about which skills remain scarce once implementation is cheap.
- **The junior developer pipeline break** Voss argues that AI eliminated the junior developer role before any replacement training pathway for product-aware engineers was built, creating a structural talent gap.
- **Product engineering as the emerging role** Voss coined the "product engineer" framing to describe the hybrid role that now commands outsized compensation premiums.
