Jason Kim is a mobile engineer at Shopify who led the Shop app migration from React Native to native Swift and Kotlin. He co-authored the Shopify Engineering case study documenting how a six-person team used coding agents to complete the full migration in twelve weeks, with one engineer first proving feasibility in a single week. His work provides concrete benchmark data on what agent-assisted mobile migrations can achieve.

## Operating themes
- **Proof-of-concept discipline.** Kim's approach to the migration began with a bounded one-week solo experiment before committing a full team, using the agent-assisted port to validate the hypothesis.
- **Parallel agent workflows.** Rather than sequential engineer-agent-review cycles, his team ran multiple agent sessions across separate git worktrees simultaneously, treating supervision as the primary engineering mode.
