Quique Fagoaga is a mobile engineer at Shopify who co-authored the case study on migrating the Shop app from React Native to native Swift and Kotlin. He contributed to the agent-assisted migration framework that allowed a six-engineer team to move the app to native in twelve weeks.

## Operating themes
- **Agent-assisted mobile development.** Fagoaga works at the intersection of AI coding agents and native platform development, treating existing implementations as agent input rather than starting from scratch.
