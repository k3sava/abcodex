Anil Madhavapeddy. Computer scientist and Professor of Computer Science at the University of Cambridge. Core maintainer of the OCaml programming language compiler and creator of MirageOS, a unikernel operating system written in OCaml. Writes from the position of a maintainer of critical open-source infrastructure, which puts him directly in the path of automated security probing that most developers observe only in theory. His August 2026 analysis of exploit timing drew on his own live server logs, real CVE incident data, and published academic research.

## Operating themes
- **Security timing in open-source disclosure** Traditional coordinated disclosure assumed defenders had days to act after a patch announcement; Madhavapeddy documents that AI agents now generate working exploits from CVE descriptions in minutes, making the disclosure process itself the attack trigger.
- **Functional systems programming** OCaml and MirageOS design: type safety and formal verification as practical defense mechanisms for production systems.
- **AI and maintainership economics** How AI tooling reshapes the cost structure for open-source maintainers, including both increased attack surface and potential productivity gains.
