Geoffrey Huntley is an independent AI engineer best known for naming and documenting the Ralph loop, a shell-based technique that feeds an agent's output and errors back into itself to enable autonomous coding cycles. His work focuses on the engineering discipline needed to make coding agents reliable in practice: deterministic enforcement patterns, architectural constraints, and the shift from writing code to explaining systems.

## Operating themes
- **Deterministic enforcement over probabilistic instruction.** Huntley argues that AGENTS.md and skill packs are probabilistic. They drift from the codebase and cannot guarantee behavior. Pre-commit hooks, CI checks, and architectural constraints are deterministic and should replace instructions for any rule that matters.
- **The residual human role.** His essay "nobody should type code by hand anymore. here's what's left." frames the remaining human function as vision, verification, and agency, not line-by-line authorship.
- **Explainability over readability.** As agent-authored codebases grow, human readers no longer trace execution line by line. The constraint shifts from readability to explainability: can you account for what the system does and why?
