Paridhi Agarwal. Engineer at Every, writing from inside a team that ships AI-powered knowledge work tools. Agarwal publishes production engineering post-mortems on the Source Code section of Every, covering decisions made while building and operating the Every Agent, a shared AI coworker for the Every team built on Anthropic's Claude Managed Agents platform.

## Operating themes
- **Infrastructure ownership trade-offs** Documenting what small engineering teams give up and gain when they cede agent infrastructure to a managed platform.
- **Coworker behavior as product surface** Distinguishing the layer that creates user value (Slack threading, permissions, shared memory) from the layer that is table stakes (uptime, token refresh, execution harness).
- **Security via architectural separation** Using platform-level constraints (no credential storage) to reduce the attack surface of production agents.
