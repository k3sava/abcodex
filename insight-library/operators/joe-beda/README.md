Joe Beda. Co-founder of Stacklok and co-creator of Kubernetes. Beda brings distributed systems design thinking from the container ecosystem to coding agent harnesses. His argument is structural: the fundamental problem with desktop-first agent designs is that they place IP, audit trails, and governance on the developer's machine rather than in enterprise-owned infrastructure. That problem does not disappear when the desktop harness is containerized.

## Operating themes
- **Agent harness architecture** The structural problems that arise when desktop-centric agent harnesses meet enterprise requirements for session durability, multi-user access, and governance.
- **Distributed systems applied to AI** Design principles from Kubernetes applied to agent loop reliability and session state management at fleet scale.
