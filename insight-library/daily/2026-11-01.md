# What landed today

Five cards, one new operator. Two themes from two sources today: a set of concrete discipline shifts for teams running coding agents at production scale, and a controlled study that places AI peer review above expert human review by every measured criterion.

## Theme 1, Coding agent discipline at production scale

Thorsten Ball posted "How I work with Agents" on X on October 25. The post lists 15 habits from working with agents daily at Sourcegraph's Amp. Four claims carry enough mechanism and specificity to stand as cards.

`ins_ball-irrefutable-proof-protocol` addresses the trust gap that opens when agents report completion. The natural end state of an agent task is a prose summary of what it did. Humans tend to accept that summary because the code looks reasonable. Asking explicitly for a demo, end-to-end walkthrough, or before/after benchmark forces the agent to build something demonstrable. Ball credits Quinn for the phrase and calls this "a major change" in handoff practice.

> "Give me irrefutable proof that this works."

`ins_ball-agent-knowledge-empirical-test` takes the same empirical discipline and applies it to the guidance files themselves. AGENTS.md files and skills accumulate over time, but written guidance that agents do not actually follow is noise. Ball's test is simple: run the same task with and without the guidance, compare results, and remove anything that shows no effect. The card formalizes what most teams skip.

`ins_ball-thread-commit-decision-link` addresses the decision context that vanishes when agents write code. Code explains what changed. The agent thread explains why and what was tried first. Without a link from commit to thread, the decision rationale decays to zero. Ball's team treats thread-to-commit links as standard practice.

> "Threads are company memory."

`ins_ball-iteration-tooling-over-chat` targets the iteration bottleneck. When a task has multiple candidate approaches, re-prompting in chat serializes the work. Asking the agent to build a comparison tool and run all variants in parallel collapses multiple turns into a single review. The human reviews one artifact, not a sequence of rounds.

Together, these four cards point to a common shift: when agents handle most implementation work, the discipline moves from writing and reviewing code to structuring the work so that evidence is durable and feedback loops are short.

- Thorsten Ball, `ins_ball-irrefutable-proof-protocol`. Demanding demos and benchmarks as deliverables replaces trust-based review with evidence-based confirmation.
- Thorsten Ball, `ins_ball-agent-knowledge-empirical-test`. Control/treatment testing is the only way to know whether AGENTS.md guidance actually changes agent behavior.
- Thorsten Ball, `ins_ball-thread-commit-decision-link`. Thread-to-commit links preserve the decision context that code alone cannot carry.
- Thorsten Ball, `ins_ball-iteration-tooling-over-chat`. Purpose-built comparison tools collapse serial chat iterations into a single parallel review.

## Theme 2, AI peer review outperforms expert human review in a controlled study

Gary King and Steven Worthington published "AI Article Reviews Dominate Human Peer Reviews at Their Best" at Harvard on October 28. The study ran 124 social science papers through rapidPeer, a Harvard pre-submission review service where papers receive paid human expert reviews. Each paper also received a Claude Opus 4.8 review using the same reviewer instructions.

`ins_king-ai-review-beats-experts` captures the headline result. AI reviews ranked above human reviews in 87 to 100 percent of pairwise comparisons. Individual scores were higher for AI on every review dimension tested. The factual error rate was 5.5 percent for AI reviews versus 15.9 percent for human reviews. A second judge model (GPT-5.5) preferred the AI review in all 132 decided pairs.

> "AI-generated reviews are better, by every measure we could construct."

The mechanism is not that the AI is smarter. It is that human peer reviewers introduce noise: variable effort, fatigue, and inconsistent application of criteria. The AI applied the same instructions consistently across all 124 papers. The study baseline was already unusually high quality; journal editors rated the human reviews positively before the comparison was run. The comparison still favored the AI.

The paper separates giving authors constructive advice, which it tested, from deciding what to publish, which it did not test. The findings apply to review quality, not editorial judgment. That said, King and Worthington argue the results are strong enough to warrant explicit journal policy for how AI review should be integrated, including a proposal for a standard AI review prompt that journals could publish.

- Gary King, `ins_king-ai-review-beats-experts`. Claude Opus 4.8 outperformed paid human expert reviewers on every measured dimension across 124 papers in a controlled Harvard study.
