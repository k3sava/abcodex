# What landed today

Four new cards from two operators. Two themes emerged from independent directions: what skills actually matter when working with coding agents, and what drives discovery for indie games in 2026.

## Agentic coding skills: instruction and verification replace code review

Simon Willison published two short posts on August 21 and 22 that clarify the skill shift behind productive coding agent use. The first, `ins_willison-instruction-over-review`, addresses the framing that working with agents requires strong code review skills. Willison argues the opposite. The two skills that matter are specifying clearly what you want and verifying at the behavior level that it happened. Granular line-by-line review was never the optimal validation method, and AI-generated code volume makes it impractical to treat it as one. His framing connects directly to the earlier `ins_willison-agentic-cost-removes-discipline` (August 19): if agentic tools remove the time-cost filter that once kept poor decisions out, this card describes the discipline that must replace it.

The second post, `ins_willison-agents-gui-zero-cost`, extends this cost-shift logic to interface choice. Developers have defaulted to terminal interfaces for personal tools because they were cheaper to build than GUIs. Willison endorses Thomas Ptacek's August 2026 argument that coding agents have erased that cost difference.

> "coding agents have reduced the cost of getting a usable-enough GUI up and running to almost nothing"

If the cost delta is near zero, the historical reason to build a TUI instead of a native interface disappears. Willison notes he runs macOS task bar apps he built this way daily.

- Simon Willison, `ins_willison-instruction-over-review`. Confident instruction and confident verification are the skills that determine coding agent productivity; code review is not the bottleneck.
- Simon Willison, `ins_willison-agents-gui-zero-cost`. Coding agents have reduced native GUI development cost to near zero, making graphical interfaces the better default for throwaway personal tools.

## Indie game growth: ideas over playbooks, widgets over social

Chris Zukowski published Parts 2 and 3 of his "Week of the Golden Age" series on August 20 and 21, analyzing the July 2026 Steam bestseller list. Two claims stand out as distinct from his earlier cards.

The first, `ins_zukowski-idea-beats-playbook`, makes the primary variable explicit. Identical marketing playbooks applied to different games produce dramatically different results. Steam's algorithmic widgets deliver the same impressions to every game they feature. What changes is what players do with those impressions. Wishlisting and purchasing are controlled by how compelling the core game idea is, not by how the store page is optimized.

> "The biggest lesson is that the idea matters more than anything else. You can polish, market and optimize a game forever, but if the core idea isn't interesting enough, it's very hard to compensate for that."

The second, `ins_zukowski-widget-beats-social`, documents the specific mechanism behind the golden age case studies. Social media virality delivers traffic spikes lasting 24 to 72 hours. Steam's New and Trending, Discovery Queue, and Personal Calendar widgets deliver sustained impressions over days and weeks. A demo launch that triggers widget inclusion outperforms a viral post across the full launch window because the widget keeps running. The "How Many Dudes" case study from Butterscotch Shenanigans makes this concrete: the game started with fewer than 500 wishlists, reached 308,000 at launch, and sold 242,000 units in the first weeks of release, all from a 7-person team with a one-year development cycle. Zukowski's editorial summary:

> "the Steam widgets are the #1 biggest driver of visibility, not social media"

- Chris Zukowski, `ins_zukowski-idea-beats-playbook`. Core game idea quality is the primary lever in marketing outcomes; identical playbooks diverge sharply based on game appeal.
- Chris Zukowski, `ins_zukowski-widget-beats-social`. Steam algorithmic widgets deliver more sustained wishlist velocity than social media virality across an indie launch window.
