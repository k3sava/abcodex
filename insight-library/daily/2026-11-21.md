# What landed today

Three cards, one new operator. Two independent themes emerged: what agents cannot replace in a living software project, and what AI search monitoring tools miss when they track only initial queries and total appearance counts.

## Theme 1, A code clone and the living project diverge from the moment the clone is made

Daniel Stenberg published exact numbers on November 17 comparing AI-generated Rust rewrites of curl with the actual curl project. Over the same roughly three-week window that multiple teams used AI agents to convert 185,000 lines of C into 340,000 lines of Rust, the curl project merged over 300 commits. More than 200 of those were bugfixes. The agent-generated rewrites have none of them.

> "During the time these agents converted 185,000 lines of C code into 340,000 lines of Rust code (I counted), we merged over 300 commits in the actual curl project."

The card `ins_stenberg-agent-clone-maintenance-gap` captures this as a case study in the structural difference between code generation and code maintenance. An agent translates existing code by iterating until tests pass against a frozen snapshot. The original project receives bug reports, security disclosures, and behavioral corrections that require reading context the agent never saw. The gap is not a temporary artifact of AI immaturity. It is structural: writing code and maintaining code are different activities, and the second requires continuous human judgment in response to real-world use.

Stenberg's argument extends to rewrites generally. He does not believe rewrites into any language are wise. The curl project's durability comes from its development speed, its team, and its community, not from its choice of language. A Rust rewrite would have prevented only 14 of 81 confirmed 2026 vulnerabilities. The other 67 are not language problems.

- Daniel Stenberg, `ins_stenberg-agent-clone-maintenance-gap`. An AI-generated code clone is a snapshot; the living project it cloned accumulates maintenance that the clone will never have.

## Theme 2, Two blind spots in AI search attribution monitoring

Kevin Indig's Q4 2026 AI search meta-analysis, published November 16, synthesizes data from multiple third-party studies. Two findings are new measurement claims that extend his earlier work on the gap between citations and brand mentions.

The first finding, documented in `ins_indig-fanout-citation-blind-spot`, comes from an AirOps study of 15,000 ChatGPT prompts. When ChatGPT retrieves pages to support an answer, it often generates implicit sub-queries. Among pages that were eventually cited, 32.9% appeared only for a follow-up sub-query, not the original user prompt. Monitoring tools that track head-query citation responses miss that entire third of a brand's retrieval footprint. A page optimized for a specific sub-topic will accumulate citations in AI answers without ever appearing in a head-query report.

The second finding, documented in `ins_indig-ghost-citation-brand-gap`, comes from a Semrush study of 3,981 AI search domain appearances. Of those appearances, 61.7% were ghost citations: the domain was used as a source but the brand name never appeared in the AI answer. Only 13.2% of appearances were both cited and named. This is a sharper quantification of a gap Indig identified in August (see `ins_indig-citation-vs-mention-depth-breadth`): being cited in AI search and being recommended as a brand are different outcomes, and they respond to different inputs. Ghost citations show that the two diverge at scale.

Together the two findings describe a monitoring problem. A brand tracking total "AI appearances" via citation count is measuring how often its content is used as evidence, filtered through tools that only watch initial queries. The actual retrieval footprint is roughly 1.5 times larger than what standard monitoring captures, and most of what gets captured produces no brand name in the answer anyway.

- Kevin Indig, `ins_indig-fanout-citation-blind-spot`. Standard AI search monitoring tools miss a third of brand citations by tracking only original queries rather than the full fan-out conversation chain.
- Kevin Indig, `ins_indig-ghost-citation-brand-gap`. More than 6 in 10 AI search domain appearances are ghost citations: the brand is used as a source but never named, so citation volume overstates actual brand visibility.
